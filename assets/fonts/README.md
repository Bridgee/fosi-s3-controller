# Font sources

Committed Noto-derived CJK subsets cover music metadata at 24 and 12 pixels.
Source: Noto Sans CJK JP Regular, copyright 2014-2021 Adobe, SIL OFL 1.1.
Full notice: [OFL-NotoSansCJK.txt](OFL-NotoSansCJK.txt).

Latin supplements derive from Montserrat Medium 7.200 in LVGL 8.4.0;
[machine-readable provenance](montserrat-source.json) records its blob/hash,
converter and character ranges. Full notice: [OFL-Montserrat.txt](OFL-Montserrat.txt).
Unicode composition data use [UNICODE-DATA-LICENSE.txt](UNICODE-DATA-LICENSE.txt).
Generated C data are committed; a normal build needs no font conversion tools.
