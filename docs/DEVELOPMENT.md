# Development

## Layout

| Path | Contents |
| --- | --- |
| `firmware/OrbitS3/` | Application, UI, network workers and committed generated assets |
| `include/` | LVGL configuration |
| `patches/` | Reviewed LilyGO driver fixes and expected driver hash |
| `assets/fonts/` | Font licenses and provenance |
| `assets/timezones/` | Timezone data provenance |
| `ai/` | English prompt, response schema and offline introduction model |
| `index.html`, `orbit-s3-preview.html` | Browser simulator and alternate embed entry |
| `assets/preview/` | Shared native geometry, font and icon masks |
| `tests/` | Synthetic fixtures and host-only fakes |
| `tools/` | Dependency preparation, repository checks and offline tests |

The display driver is pinned to LilyGO commit
`359c03f7cd8e9aaadd4bf0f3fbf790844fd95f98` with the included safety patch.
PlatformIO Espressif32 6.9.0 uses Arduino-ESP32 2.0.17; LVGL is 8.4.0.
Other library versions are pinned in `platformio.ini`. Arduino 3/LVGL 9 require
a separate port. The current target is the full-circle 2.1-inch T-RGB.

The main thread owns LVGL. A state/control worker handles the S3 API; a shared
media worker serializes artwork, weather and lyrics. Optional AI has bounded
queues, cancellation/generation checks and a separate, default-disabled worker.
Display idle pauses rendering while control/state work continues.

Generated fonts, icons and timezone tables are committed, so ordinary builds do
not need font tools, a browser, a local server or the original development workspace.
English UI text is separate from multilingual music metadata and test fixtures.
The `OrbitS3` source folder and configuration prefix are retained for compatibility.

## Build and test

After the README setup:

```sh
python tools/check_repository.py
pio run -e orbit-live-check -e orbit-intro-mock -e orbit-ai-check
python tools/test_native.py
```

Host tests need a C++ compiler with AddressSanitizer/UndefinedBehaviorSanitizer.
They compile production parsers/policies and workers with fake clocks, queues,
HTTP and TLS. They do not open device ports or make API requests. Build preparation
and PlatformIO dependency downloads do require internet on a fresh checkout.

| Environment | Purpose | Upload allowed |
| --- | --- | --- |
| `orbit-demo` | Offline display demo | Yes |
| `orbit-live` | Configured display controller | Yes |
| `orbit-live-check` | Complete network link check, no private configuration | No |
| `orbit-intro-mock` | Synthetic introduction flow | No |
| `orbit-ai-check` | Real adapter link check, runtime disabled | No |

CI checks repository contents, builds the four credential-free targets and runs
host tests. It does not upload binaries. Local tests cannot establish physical
panel performance, real service compatibility or peak concurrent TLS memory.

## Simulator maintenance

Node.js 22 or later is used by the browser regression tests. Regenerate after a
UI/version change, then check both public entries:

```sh
python tools/sync_preview.py
python tools/sync_preview.py --check
python tools/test_preview_sync.py
node tools/test_preview_parity.cjs
node tools/test_preview_transitions.cjs
node tools/test_music_intro.cjs
python tools/test_swipes.py
python tools/test_preview_lyrics.py
python tools/test_preview_server.py
```

The build guard rejects stale generated previews. `sync_preview.py` uses the
already-pinned LVGL sources to regenerate shared masks and the alternate HTML.
Native screenshots are generated by `test_ui.py`; keep its `artifacts/` outputs
out of Git. No original development archive is needed by either simulator.

## Contributions

Keep changes focused, include an offline regression for protocol/lifecycle fixes,
and update the relevant documentation. Register new public files in
`repository-files.json`; run the repository check before committing. It rejects
unexpected tracked files, known credential patterns, private paths and broken
local documentation links. Do not commit credentials, captured responses, album
art, serial logs, build directories or device binaries. Report security problems
privately through the repository's security advisory feature when available.
